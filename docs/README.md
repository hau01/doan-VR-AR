# DOAN_VR-AR

This repository contains a simple starter structure for a VR/AR tourism project.

## Project structure
- `frontend/` contains the React application.
- `backend/` contains the Node.js API.
- `assets/` stores multimedia resources.
- `docs/` stores documentation.

## Run frontend
```bash
cd frontend
npm install
npm run dev
```

## Run backend
```bash
cd backend
npm install
npm run dev
```
